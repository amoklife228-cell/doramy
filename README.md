# Дорамы

Веб-приложение (PWA) для просмотра каталога дорам и ведения личной библиотеки. Ставится на iPhone из Safari через «На экран Домой», работает офлайн с уже загруженными данными.

**Открыть:** https://amoklife228-cell.github.io/doramy/

## Возможности

- **Каталог** — дорамы Кореи, Японии, Китая, Тайваня, Таиланда и Гонконга; фильтр по стране и жанру, сортировка по популярности, рейтингу и дате выхода, бесконечная прокрутка.
- **Поиск** — по названию на русском, английском или в оригинале.
- **Библиотека** — статусы «Хочу посмотреть / Смотрю / Просмотрено / Отложено / Брошено», избранное, счётчик серий с прогрессом, оценка 1–10, заметки; фильтры, поиск и 7 вариантов сортировки.
- **Карточка** — постер, описание, премьера, статус выхода, серии и сезоны, жанры, рейтинг TMDB.
- **Резервная копия** — экспорт и импорт библиотеки в JSON.

## Ключ TMDB

Данные берутся из [TMDB](https://www.themoviedb.org). Нужен бесплатный ключ: зарегистрируйтесь, откройте [Settings → API](https://www.themoviedb.org/settings/api) и скопируйте «API Key» или «API Read Access Token». Вставьте его в приложении на вкладке «Настройки». Ключ хранится только в браузере на вашем устройстве.

## Разработка

```bash
npm install
npm run icons   # генерирует PNG-иконки в public/
npm run dev     # http://localhost:5173/doramy/
npm run build   # проверка типов + сборка в dist/
```

Стек: React 18, TypeScript, Vite, Dexie (IndexedDB), vite-plugin-pwa. Деплой на GitHub Pages выполняется автоматически при пуше в `main` (см. `.github/workflows/deploy.yml`).

## Структура

```
src/
  lib/        tmdb.ts (API), db.ts (IndexedDB), router.ts (hash-роутинг), usePagedList.ts
  screens/    Catalog, Search, Library, Detail, Settings
  components/ DramaGrid, Chips, Poster, TabBar
scripts/make-icons.mjs   генератор иконок без зависимостей
```

Этот продукт использует TMDB API, но не одобрен и не сертифицирован TMDB.
